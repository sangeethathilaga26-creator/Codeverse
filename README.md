# Codeverse

A study roadmap and progress-tracker web app for IT, BCA, and CS students — helping them follow a structured path through core programming subjects with practical tips at each stage.

🔗 **Live Demo:** https://codeverse-wt52.onrender.com
## Features

- 📍 Year-wise roadmap (Year 1 to Year 3) for core subjects
- ✅ Progress tracker — mark topics as Not Started / In Progress / Completed
- 🔐 User authentication — Signup, Login, Logout
- ⚠️ "Avoid" tips for each topic based on real mistakes students make
## Tech Stack

- **Backend:** Django 6.0.7 (Python)
- **Frontend:** HTML, Bootstrap 5.3.3
- **Database:** PostgreSQL (Render) / SQLite (local dev)
- **Deployment:** Render, Gunicorn, WhiteNoise

## Run Locally

1. Clone the repository

2. Create and activate a virtual environment

3. Install dependencies

4. Run migrations

5. Start the server

6. Visit `http://127.0.0.1:8000` in your browser
